# Ankit Kumar — Portfolio

A responsive, aesthetic portfolio website for Ankit Kumar, B.Tech CSE 2nd-year student at Katihar Engineering College.

## Run locally
Open `index.html` in any modern browser.

## Customize
- Replace project descriptions/links in `index.html`.
- Add GitHub and other social links in the Contact section.
- Replace `assets/profile.png` if you want to use another profile photo.
